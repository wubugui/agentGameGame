# 离开山谷以前

一段约 8–12 分钟的第一人称节点式点击叙事原型。玩家在黄昏的山脊发现一封无法读懂的信，误判返程距离后独自穿过夜林；遗失的手机在几小时后以无法解释的方式被归还，那封信也因此获得了新的含义。

## 体验结构

- 固定视点的 2D 场景探索，不使用自由行走或传统背包谜题
- 手机贯穿地图、相机、相册、电量与翻译叙事
- 包含手电寻路、拦车、搜寻与图像翻译等一次性交互
- 单线、单结局，重点是“轻微诡异，但最终治愈”的情绪闭环

## 本地运行

```bash
npm install
npm run dev
```

美术场景由 GPT Image 为本原型定制生成。
