# 离开山谷以前

一段约 15–25 分钟的第一人称 2.5D 旅行冒险。

一位刚在英国读完一年书、下周就要回国的年轻女孩，临时起意走进意大利多洛米蒂的山里。登山学校的教练把地图转过来，铅笔画了一条飞拉达路线，说两个小时就能登顶。她在山顶掰了半块巧克力，在信箱里读到一张读不懂的纸，看见坡顶亮着窗的山屋，看见林线边的鹿；天黑后打了一通谁也听不清的求助电话，靠一盏补光灯一小块一小块地走下山，在黑暗里找到 656 号路标，抓着树根爬上路基，遇到一对陌生的情侣，弄丢了装着这一年所有照片的手机，做好了失去它的准备。然后，它毫无预兆地回到了她手里。

离开山谷以前，她把那张纸翻译了出来。

## 体验

- 第一人称，不露出身体；她的一切都通过手机、随身物、拍照习惯和自言自语建立。
- 手机贯穿全程：消息、地图、相机、相册。玩家自己构图拍下的照片，就是这次旅程的证据。
- 铁索、碎石坡、夜路落脚点等轻量通过，让玩家亲手走过这段路。
- 单线、单结局。结尾是相册里那张信的照片，和上车前回头看的一眼。

创作灵感来自 B 站 UP 主「塑料叉FOKU」分享的一段亲身经历。游戏中的事件顺序、信件原文、手机失而复得的方式都以那段经历为准。

## 本地运行

```bash
npm install
npm run dev
```
