## 1. 参考作品转化清单

参考方向不是复制某一款游戏，而是组合四种已验证的能力：

- 《The Star Named EOS》/《Behind the Frame》：手绘有限场景中的环视、取景与空间感。
- 《SEASON》：玩家自主决定什么值得拍，并在旅程后回看自己的记录。
- 《A Normal Lost Phone》/《Bury Me, My Love》：手机本身承载人物生活，消息按时间和行动推进。
- 《Firewatch》/《Open Roads》：移动过程中维持远程关系，让路途本身发生内容。

## 3. 迭代原则

1. 每轮只验证一个核心假设。
2. 任何新内容必须先对照 `DESIGN_LOCK.md` 3.1 的事实清单；与原经历冲突的不做。
3. 任何新系统必须直接服务"她的这一天"和"被世界善待的命运感"；解释不清情绪功能的系统不加入。
4. 每个阶段都保持可从头运行到结尾。
5. 每次线上更新保留版本标签和简短试玩问卷。

## 4. 试玩验证

### A 轮：形式验证（5–8 人）

只测试前 15 分钟。验证它是否首先被感知为一位年轻女孩的旅行。

### B 轮：情绪验证（8–12 人）

测试完整流程。记录望见山屋、获救、准备失去、归还、读到译文五个节点的口述反应。

### C 轮：陌生玩家验证（15–30 人）

不提供主题说明。通过问卷确认玩家是否自行说出"被世界温柔对待"一类的表达，以及是否愿意把"你是特别的"接下来。

放行标准：

- 80% 以上玩家首先将作品描述为旅行 / 爬山 / 一个人。
- 70% 以上玩家能描述主角的年龄感和两个以上性格特征。
- 70% 以上玩家在归还时使用"巧、幸运、温暖、奇妙"中的至少一种近义表达。
- 多数玩家会在相册里停留，并主动回看那张信的照片。
