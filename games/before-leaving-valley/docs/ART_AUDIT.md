# 美术审查：背景画里不许烘焙任何会动的东西

审查日期：2026-09-04
审查对象：`public/pano/*.webp`（jpg 副本在 `scratchpad/gen/pano3/`）与 `public/sprites/*.webp`（png 原图在 `scratchpad/gen/sprites3/`）
事实依据：`docs/SOURCE_TRANSCRIPT.md`；形式依据：`docs/DESIGN_LOCK.md`

## 0. 审查准则（业主定的硬规矩）

**背景画只画不会动、不会被拿走、不会改变状态的东西。**
凡是她会捡起、会使用、会打开、会穿上的道具，凡是人、动物、车辆、飞行器、灯光，一律从画里抠掉，改成独立 sprite 贴回画面。
理由不是洁癖：烘焙进去的东西没法被看向、没法被拿、没法在夜里被光束照到、没法在她丢了手机以后消失。玩家伸手去碰一张画，画不会回应——这正是"点哪都能过"的反面。

## 1. 坐标换算约定（本文件所有 yaw/pitch 都按此计算）

渲染器把 DOM 锚点按 `data-yaw` / `data-pitch`（度）投影到球面片上。以未经修改的 1280×720 原画正中为原点：

```
yaw   = (x - 640) × 0.071          x = 640 + yaw   / 0.071
pitch = (360 - y) × 0.083          y = 360 - pitch / 0.083
```

`distance` 控制缩放：渲染器按 `10 / distance` 缩放元素，**10 = 自然大小**，越大越远越小。
`sizeVh` 在本文件里一律指**最终屏幕上的高度**（16:9 窗口，竖直视野 60°）。
因此 CSS 里要写的 `height` = `sizeVh × distance / 10`。
（例：`sizeVh: 6`、`distance: 12` → CSS `height: 7.2vh`。）

粗略的合理性校验：一个 1.65 m 的人，距离 d 米时占屏幕高度约 `143 / d` vh。5 m → 29vh，10 m → 14vh，30 m → 4.8vh。
一头 1.2 m 的马鹿在 25 m 外只有 4.8vh。一辆 3 m 高的公交在 35 m 外只有 8.6vh。
