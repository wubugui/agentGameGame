# 《离开山谷以前》游戏设计 v4.0

状态：**待实现**（2026-09-04 综合三份提案与两轮评审后定稿）
事实依据：`docs/SOURCE_TRANSCRIPT.md`。凡与事实文件冲突的设定一律以事实文件为准。
形式依据：`docs/DESIGN_LOCK.md` v3.0 第 4 节（Myst III / Riven 节点环视）。本文件取代 DESIGN_LOCK 第 5 节的玩法部分，其余各节继续有效。

采用的骨架：**结果锁死，能动性全部落在"怎么做、按什么顺序做、做到什么程度、为此花掉多少"**。
原经历里发生过的事，一件都不能被玩家改变：她拍下了那封信、她登顶、她当场决定紧急下撤、她惊到了鹿、她打了 112、她在森林里掉了手机、第一辆车过去了第二辆停下、第三天手机从警局回到她手上、她在长椅上翻译了那张纸。玩家能改变的只有这一天的**质地**。

## 1 设计宣言：为什么这是游戏，不是视觉小说

### 1.1 现在这一版为什么不是游戏

当前 23 个节点串成一条线，每个节点有且只有一件必做的事，做完 `isReady()` 放行、`go` 箭头出现、往前一步。玩家从头到尾没有回答过任何一个问题：没有"我要去哪"，没有"我现在花不花这个时间"，没有"我错过了什么"。每个节点入场自动播报 `thoughts[0]`，把这个地方是什么、要干什么、她心里怎么想，一次说完。这是**带着操作动画的视觉小说**：你按的每一下都只是把叙述往前推一格。

### 1.2 变成游戏的唯一支点

她自己的总结已经把答案写好了：

> 那一天犯了很多错误：过于轻信导游，没有二次确认路线难度，**低估了不熟悉路线时在岔路口看地图、认石头上的标志以及拍摄所需要的时间**。

**这一天的失败是时间的失败。** 教练说六七个小时，实际至少十个小时，日落 20:15，她 23:00 才走到公路。于是：

- 一条从 09:40 走到深夜的**连续的钟**（复用 `phone.minuteOfDay`，它已经存在）；
- 屏幕上**永远没有倒计时、没有分数、没有结算评价**；时间的唯一读数是天上的太阳和手机锁屏；
- 玩家做的每一个动作都在花分钟——看一块铜牌、认一处漆记、摊一次地图、拍一张照、在山顶多站一会儿、路牌选错；
- 分钟花完变成黑暗，黑暗让热点的显现半径收窄、让心跳变快、让每一步的按住变长。

玩家不是在"点过剧情"，而是在**回答同一个问题一百遍：这一分钟值不值得**。她犯过的每一个错误，玩家都可以在完全不被提醒的情况下自己犯一遍。最后当她做好了永远失去的准备、命运经由很多人的手把手机送回来时，那份被善待的感觉之所以立得住，是因为**那一天是玩家自己挥霍掉的**。

### 1.3 五条不可让步的原则

| # | 原则 | 具体含义 |
|---|---|---|
| 1 | **结果锁死，过程开放** | 所有事件都会发生且顺序不变。玩家只决定怎么做、什么顺序、多彻底、花多少。任何一条"她那天没做的事"都不可玩。 |
| 2 | **沉默是默认状态** | 一个玩家什么都不碰就穿过的节点，一个字都不说。删除全部入场自动独白。 |
| 3 | **信息在世界里，不在旁白里** | 铜牌、路牌、地图图例、木雕、便签纸、石头上的漆——全部做成要凑近看的画面元素。她绝不复述任何一件玩家自己能读到的东西。 |
| 4 | **没有失败画面** | 没有 game over，没有重来点，没有"你错了"。所有代价折算成分钟、光、体力、电、以及永久错过的内容。 |
| 5 | **系统只在第一天用力** | 第二天和第三天几乎撤掉全部资源压力，让玩家从第一天的紧绷里被放下来。全游戏最贵的两个可选动作（跟那两位攀登者点头、酒店里关掉 Find My）不给任何机制回报，只给意义。 |

## 2 核心循环

### 2.1 六个动词（全部长在画面里，没有菜单）

| 动词 | 输入 | 代价 | 作用 |
|---|---|---|---|
| **看** | 视线停在画面某物 0.6–1.2 秒，它自己浮现 | 0–1 分钟 | 唯一的"搜索"。热点只在视线靠近时显现，看＝找。 |
| **点** | 点击已显现的热点 | 1–4 分钟 | 拿起、打开、挂上、踩上去、确认一处漆记。 |
| **按住** | 按住不放（鼠标 / Enter / 空格） | 时间 + 体力 | 攀爬、抓握、低吼、稳住身体。 |
| **等** | 指针 4 秒不动，视线停在一处风景上 | 1 分钟 / 8 秒 | 唯一的休息（回体力），也是"看久了才看见"的东西的唯一触发。 |
| **背包** | `I` 或画面下缘胸前挂扣 | 摊开 / 收起各 30 秒 | 装备与道具。一张铺在地上的手绘布，不是网格 UI。 |
| **手机** | `P` | 开屏 1 分钟 · 1%（夜里 4%） | 时钟、电量、离线地图、相册、消息、行程备忘。 |

森林里额外两个：**喊一声**（点 / 空格，心跳 −0.40，体力 −2，冷却 4 秒）与**低吼**（按住空格，心跳 −0.05/秒，体力几乎不涨，**但按住低吼期间无法按住把手**）。

### 2.2 节点内的循环

```
站定
 └─ 看：视线扫过画面，热点在靠近时浮现（这一步没有任何提示）
     └─ 认：找石头上的红-白-红漆记，确认这一段走对了
     └─ 读：铜牌 / 路牌 / 木雕 / 时刻表 / 便签 → 写进本子（信息成为道具）
     └─ 用身体：挂锁扣、抠手点、选落脚点、按住往上爬
     └─ 等：站着不动回体力，看见只有站久了才看得见的东西
 └─ 判断：哪些值得花时间，哪些不值得
 └─ 环境立刻回应：光变了、手在抖、电量掉一格、相册多一张、脚下的沙滑走了
 └─ "往前"的箭头显现（该节点的必做动作完成后）
 └─ 走：钟往前跳，天色随钟往前变
```

### 2.3 跨节点的循环

> **你在上面省下的每一分钟，都在下面变成脚下多出来的光；你在上面省下的每一分体力，都在夜里变成少按住的那半秒。**

这条因果线最长的一段：钢缆上每个锚点选"拉钢缆"（快、费手）还是"找岩点"（慢、不费手）——中午省下的 16 分钟，晚上要在森林里以每个把手多按住 0.25 秒还回去。

## 3 系统

共 8 个系统。其中只有 3 个（天光、电、手）会被玩家意识到，其余全部只以画面和声音存在。**任何一个系统如果需要一段教学文字才能被理解，就删掉它。**

### 3.1 天光（钟与光）— 主系统

- **目的**：把"教练说六七个小时、实际至少十个小时"这个事实，变成一块玩家自己去花的预算。让所有决策共用一个可见的代价单位。
- **规则**：
  - 复用 `phone.minuteOfDay` 作为唯一真实时钟，09:40 起算。日落 **20:15**，最后一点可用光 **21:05**。
  - 每个节点的 `NODES.minutes` 重新配平（见下表），玩家的动作在其上叠加。
  - 新增 `light = clamp01((sunsetMinute - now) / 90)`：>0 是白昼到暮色的连续量，=0 是日落，之后为夜。
  - `light` 驱动三件事：① `PanoStage` 的 `TINT` 从 day 连续插值到 dusk 再到 night（**删掉按节点写死的 `light` 字段，改成按钟算**）；② 所有 `data-reveal` 半径 × `(0.55 + 0.45·light)`，但**硬下限 11°**；③ 夜间脚步与呼吸的音量随光下降上升。
  - **必须修掉的现存缺陷**：`App.tsx` 的 `dusk` 目前由 `nodeSeconds` 计算——站着不动天就会黑。改为纯按故事时钟。
- **重新配平的行程时间**（基准值，单位分钟；玩家动作在其上叠加 0–90）：

  | 节点 | 走到下一个节点 | 基准到达时刻 |
  |---|---:|---|
  | roadside | 10 | 09:40 |
  | meadow | 20 | 09:50 |
  | approach | 15 | 10:10 |
  | plaque | 5 | 10:25 |
  | cable | 90 | 10:30 |
  | crack | 60 | 12:00 |
  | mailbox | 25 | 13:00 |
  | exit | 110 | 13:25 |
  | summit | 20 | 15:15 |
  | plateau | 25 | 15:35 |
  | hutView | 60 | 16:00 |
  | signpost | 40 | 17:00 |
  | scree | 100 | 17:40 |
  | deer | 55 | 19:20 |
  | forestEdge | 30 | 20:15 ← **日落正好落在林缘** |
  | forest1 | 50 | 20:45 |
  | forest2 | 70 | 21:35 |
  | hairpin | 25 | 22:45 |
  | car | — | 23:10 ← **与原经历"23:00 才走到公路"一致** |

  校验点：到达 hutView 是 16:00，距 09:40 已 6 h 20；加上墙上的可选动作正好落在 `HOURS_ALREADY = 6.5`。摊开地图算出的下撤合计 `MAP_LEGS` = 3.5 h，6.5 + 3.5 = **10 h**，与她原话"至少十个小时"一致。
- **环境反馈**：从不显示倒计时。三个诊断口——手机锁屏的时间（按 P，夜里要花 4% 电并毁掉夜视 20 秒）；画面本身的色温与云影密度逐分钟推移；纸地图右下角印着一条日落刻度尺，铅笔可以把"现在"那一格划掉。声音上：18:00 起蟋蟀渐入，19:30 起风换向，20:15 太阳落到 Sassolungo 后面时环境声整体降 3 dB，只剩风。
- **失败与恢复**：没有"天黑失败"，只有"天黑以后一切更慢"。**夹紧**：不论玩家怎么省，进入 forest1 一定在天黑之后，到达 hairpin 一定在末班车之后——原经历的形状不可被优化掉。恢复手段只有一个：不再乱花。

### 3.2 手（体力）

- **目的**：把"此时已经攀岩加徒步十小时，体力早已耗尽，是肾上腺素在推着我走"变成一条玩家全程管理的曲线。
- **规则**：`fatigue` 0–1，起始 0。
  - 上升：拉钢缆过一个锚点 +0.06、裂缝跳步 +0.10、滑一次 +0.05、跑沙一步 +0.02、阵风 +0.01、不吃巧克力则全程 +0.15 常数。
  - 下降：**等**（站着不动 −0.04/8 秒，任何节点）、巧克力 −0.25、山顶坐下 −0.05/8 秒、车里接过那瓶水 −0.20。
  - 作用点（全部接在已有代码上）：`PanoStage` 的 `tension` 吃 `fatigue`（手抖、画面颤）；森林 `CLIMB_HOLD_MS × (1 + fear×0.9 + fatigue×0.6)`；热点 `data-reveal` 半径 × `(1 − fatigue×0.35)`（累了的眼睛看见的更少，但仍受 11° 下限保护）；`GAIT.pitchOffset` 随体力下压最多 4°（镜头下沉）；呼吸声频率。
  - `fatigue ≥ 0.9` 进入**肾上腺素**状态：不再有额外惩罚，但一切动作花双倍分钟，画面边缘压暗，色彩去饱和 25%，**她不再说话**。这不会杀死玩家，只会让这一夜非常长。
- **环境反馈**：**没有血条，没有数字，也没有"显示身体状态"的设置开关**（那个开关是承认诊断通道失败）。三条通道必须做到灵敏可靠：呼吸声（`Soundscape.exhale` 的频率与低通截止）、手抖（已有 `tension`）、镜头下沉（`GAIT.pitchOffset`）。玩家想知道自己还剩多少，唯一的办法是站着歇一口气，从那口气有多长自己判断。
- **失败与恢复**：体力从不阻止任何动作。恢复永远存在且永远要花时间：**等**（任何节点，随时）、巧克力（全天唯一一顿饭，什么时候吃由玩家定）、车里那瓶水。

### 3.3 心跳（夜里的恐惧）

- **目的**：把"一直发出很粗重的声音给自己壮胆"做成一个有取舍的持续行为，而不是一个降恐惧按钮。
- **规则**：`fear` 0–1，只在 forestEdge / forest1 / forest2 存在（`hairpin` 归零，已有）。
  - 上升：每完成一个把手 +0.16、松手 +0.08、窄光 ×1.4、光束静止超过 8 秒 +0.05、打开手机 +0.12（并且随后 20 秒 reveal ×0.6）、第一天看过木雕（熊/狼/野猪）则起点 +0.10。
  - 下降：**喊一声** −0.40（体力 −2，冷却 4 秒）；**低吼**（按住）−0.05/秒，**期间无法按住把手**；找到树干上的 656 漆记 −0.25；巧克力 −0.15。
  - **这是全设计最干净的一个机制**：每一步都是"先把恐惧压下去再爬（慢、稳），还是带着恐惧直接爬（快、按住更久、更容易松手）"。
- **环境反馈**：保留现有心跳条（只在森林两节点出现），但**去掉数字**，只让画面边缘随心跳一涨一缩。喊出去的那一声在山谷里有回声。
- **失败与恢复**：`fear` 高只让路更长，从不挡住路。松手＝"手松了。再来。"5 秒，`fear` +0.08，永远不会掉下去。

### 3.4 三块电

- **目的**：原经历里"相机先没电，手机也快没电，特别特别幸运我带了一盏拍视频用的补光灯"是三条独立的电量线，救她的是第三条。
- **规则**：
  - **相机（Insta360 X4）**：独立电量，只用于山顶自拍与少量拍摄。**在 forestEdge 按事实归零**（已有 `cameraDead`）。玩家第一次得知这件事的方式是：在 forestEdge 掏出手机时，相机图标是灰的——不是旁白告诉他的。
  - **手机**：沿用现有 `battery`（起始 82）。新增：每次开屏 −1%（夜里 −4%），离线地图每分钟 −2%，112 通话 −6%。事实钉子：挂断 112 后固定为 8%。**拍照永远不产生任何负面文本**；省电的唯一回报是森林里能多摊开一次离线地图（很小），多拍的回报是警察局里更长的相册（很大）。
  - **补光灯**：**全游戏唯一没有任何数字的资源**。唯一 UI 是光圈的**直径**与**颜色**（满电冷白 → 半电偏黄 → 快没电时边缘发红并一跳一跳）。光束半径直接乘进 forest1 / forest2 每一个热点的 `data-reveal` 半径（下限仍是 11°）。在 forestEdge 选咬法：**宽光**（三个把手都被照到但都很暗，reveal 22°，每个把手要多看 0.4 秒才显形，每分钟 −1.6）或**窄光**（只有一个把手亮得刺眼，reveal 9°→按下限 11°，瞬间显形，但四周全黑，`fear` 上升 ×1.4，每分钟 −0.9）。切换咬法花 20 秒且期间不能攀爬。摊开纸地图时补光灯必须照纸，那几十秒里地面全黑。
- **环境反馈**：相机的电只在举起相机时看得到（取景器角落）；手机的电在锁屏上；补光灯什么数字都没有。
- **失败与恢复**：补光灯到 0 不是结束——光变成一点暗红的余烬，reveal ×0.45（仍不低于 11°），按住时长 ×2，她继续爬。**她走出来了，灯没有真的死**：电量下限夹在 0.15，最后一段自动变暗一档。

### 3.5 红白漆记（认路）

- **目的**：她自己点名的东西："低估了在岔路口看地图、认石头上的标志所需要的时间。"这是让每个户外节点都有真判断的系统，也是最省成本的"可选发现"。
- **规则**：
  - 每个户外节点在画面里有 **2–4 个候选记号**（DOM 热点，`data-reveal` 统一 **12°**，标签统一是"石头上的记号"，真假在凑近之前完全不可分辨）。
  - 点一个 → 她凑近看 → 判定：真记号（红-白-红漆条，或漆着 649 / 656 的路桩）/ 假记号（地衣、铁锈痕、别的路线留下的旧箭头、测量点）。
  - 确认真记号：这一段 `certainty = true`，往前走不额外花时间，记号在画面上留一道极淡的高光直到离开节点。确认假记号：−1 分钟，该点变灰不再可点。
  - **没有确认就往前走：永远允许**，但按节点扣 8（草甸）/ 12（碎石路、顶段）/ 15（高原）/ 20（夜森林）分钟，她的独白只有一句"走错了一小段"，夜里另外 +0.1 心跳。
  - **铁律：找到漆记只是确认与省时，正确出口在没找到时也永远可走。** 漆记从来不是锁。
  - 第一次在 approach 或 plaque 看到并停留满 1 秒，触发一次辨认（"红白红。跟着这个走。"）。**学会之后**所有漆记在视线经过时会短暂地亮一下——那不是 UI 高亮，是她的注意力。没学会：漆记只是石头上的旧漆，视线经过毫无反应。
- **环境反馈**：确认成功——她伸手抹掉记号上的灰（复用 `hand-grip` 精灵），一声轻微的布擦石头。确认失败——她把手收回来，没有声音。走对了整段路：下一个节点入场时她不喘气；走错过：入场时多一次 `recover()`。
- **失败与恢复**：认错只扣 1 分钟。不认也永远能走。纸地图的图例上印着每一段应该有几个记号——读过地图的玩家知道该找几个。

### 3.6 背包（唯一的"界面"，一块布）

- **目的**：取消菜单，把装备决策变成把东西拿出来、戴上、塞回去的物理动作。
- **规则**：画面下缘一个常驻热点（胸前挂扣，pitch −13），`I` 或点击展开。展开是**一张铺在石头上的手绘布**（全屏 overlay，画的是布与实物，没有格子线、没有列表），最多 16 件。展开与收起各 30 秒游戏时间。
  - 三类：**穿在身上的**（头盔、安全带挽索、手套、帽子、冲锋衣）——穿戴与否改变别的系统的系数；**要用的**（相机、手机、补光灯、纸地图与铅笔、巧克力）——从包里拿出来才能用，拿出来占一只手（夜里拿地图＝光照纸不照地）；**带回来的**（那对情侣的联系方式）。
  - **在 plaque 节点，头盔与挽索必须从这块布上拿出来戴上**，这是全片第一次装备检查，顺序不对时她的手自己收回来，不弹任何字。
  - 手机在 forest2 第三步滑出去以后，包里那一格变成空的轮廓，所有以手机为前提的动作在包里就是灰的——**玩家不需要被通知，他打开包自己看见**。
- **环境反馈**：布会随着这一天变脏——草甸上是干净的，碎石坡以后有灰，森林以后有泥和松针，第三天警局里她重新把它整理好。东西被拿走后布上留下压痕。
- **失败与恢复**：没有失败。忘了带的东西没有惩罚，只有后果（不戴手套则裂缝每个手点多 0.02 体力并且她说石头扎手）。

### 3.7 本子与纸地图（信息即道具 + 目标呈现）

- **目的**：让"知道一件事"本身成为可获得、可错过、可在后面被用到的道具（Outer Wilds 的飞船日志）；并把唯一的"目标列表"做成她真的带着的那张纸。
- **规则**：
  - **本子是纸地图的背面，铅笔写的。** 每条 entry 只有一行，全部来自世界里可读的东西，**没有一条是旁白送的**。
  - entry 是**别的系统的输入**：
    - 没有 `E-carabinerRule`（起点第二块牌子上的安全规则）→ 钢缆节点的锁扣面板**只显示颜色，不显示状态文字**，玩家得自己记住哪把在上面。
    - 没有从起点或路牌读到的分段时间 → hutView 摊开地图时那几行显示 **`?`**，必须用一个估算滑块自己填，**她的估值就是合计用的数**。信息不全的玩家做的正是她那天做的那个决定。
    - 没有 `E-656` → 路牌四条臂读起来一样可信。
    - 没有 `E-forest`（木雕上的熊、狼、野猪）→ 鹿群跑走以后她只想到鹿；有了才有那句原话，森林 `fear` 起点 +0.10 且"喊一声"效果 ×1.3。
  - **纸地图取代现在的勾选列表**：一张手绘的 Tabacco 05，摊开是把纸铺在石头上，**用手指沿画出来的路线划过去，小时数在指尖下累加**，铅笔痕留在纸上；纸边缘印着 `tramonto 20:15`（唯一能拿到确切日落时间的地方）与一条日落刻度尺。三种操作：勾一段（把这一段的时间记进合计）、在"现在"那一格划一道（读出还剩几小时天光）、写一行（当前目标）。
  - 摊开花 0.3 分钟；风大的节点（cable / exit / summit / plateau）要用石头压住（多 30 秒）；夜里除了 0.3 分钟还要把补光灯照在纸上（地面全黑，心跳 +0.03/秒）。
  - **合计栏是活的，但它从不跳出结论**——只有一个铅笔写的数字和旁边一条划掉的日落刻度。
- **环境反馈**：获得一条 entry＝铅笔在纸上写一行的声音，屏幕角落什么都不弹。玩家只有翻开本子才看得见自己知道多少。地图会被这一天弄旧：折痕、山口的风把一角吹翻、夜里补光灯照上去纸是暖黄的。
- **失败与恢复**：漏读任何一条都不影响通关。**所有信息点都有第二来源**（漆记 ↔ 地图图例；分段时间 ↔ 起点展示牌与路牌；木雕 ↔ 林缘的路牌），漏掉只改变台词的落点与心理起点。

### 3.8 世界的回应（凝视触发 + 环境记忆）

- **目的**：兑现"环境响应"，并干掉最后一条让这个 build 读起来像幻灯片的反射——`setTimeout` 推剧情。
- **规则**：
  - **凝视触发取代计时器**：两位攀登者（exit）、直升机（summit）、鹿群（deer）、第一辆车（hairpin）、那位女士（busStop）都是**进画面然后等着**。它们的节拍只在视线停在其 ~14° 内 0.6 秒时才触发。`PanoStage` 已有 `onGaze`，这几乎是免费的。在此之前它们就站着、就怠速、车灯就再扫一次树干。**没有任何一个 timeout 会替玩家把它们点着。**
  - **声音先到并且偏在一侧**：蹄声在右边、引擎在下方偏左、长椅后面的脚踩碎石——复用已有的 `setWindPan` / `panned()`。玩家因为听见了才转头，这是在真实的地方看东西的方式。
  - **环境记忆**：① 在 forestEdge 喊过一声，deer 节点的鹿已经走了，只剩蹄印和草上的压痕；② 17:00 山屋的窗户亮起来——如果玩家还在 hutView，能看见它亮，那是他放弃的那个地方在跟他说晚安；③ 确认过的漆记留下高光；④ 第二天回到森林小路，昨晚玩家走过的那一段草是倒的；⑤ 第三天的公交站与第一天的 roadside 是同一个机位，相册里两张会挨在一起。
- **环境反馈**：全部是画面与声音，**没有一条走文字**。
- **失败与恢复**：不适用。这个系统只有"发生了"和"没发生"。

## 10 叙事政策

### 10.1 目标

**全程至少 60% 的时间，画面上没有任何文字。** 一个玩家什么都不碰就穿过的节点，一个字都不说。

### 10.2 七条规则

1. **删除全部入场自动播报。** `App.tsx` 里"进入节点 → 显示 `NODES[node].thoughts[0]`"的逻辑取消。`thoughts` 降级为兜底：**玩家进入后 2 秒内没有做任何动作**才出现一句（她站定了，在看）；玩家一动手，这句话直接丢弃，不排队、不补发。**一局最多兜底三次。** 章节卡期间不出任何独白。
2. **她只在玩家动手之后、或世界动了之后开口。** 确认一处漆记、抓到一块烂树根、鹿抬起头、直升机飞过、车灯扫上来。纯粹的"看"不配独白，最多给她半句（≤12 字），或者干脆只给一个声音。
3. **一次只有一行，永远不排队。** 现有的 `say(..., delay)` 连播全部拆成由玩家的下一个动作触发。**具体要拆的三处**：`chooseRetreat()` 里 6.5 秒后追加的第二句；`takeSelfie()` 里 9 秒后追加的那句；`hangUp()` 里把五件事塞进一句的长台词。
4. **世界里能读到的东西她绝不复述。** 铜牌、路牌、时刻表、地图图例、木雕、信箱里的纸——全部做成可凑近读的画面元素，读完写进本子，她一个字都不说。**必须删除的具体一句**：`chooseRetreat()` 里 `say("地图上一段一段加起来，从头到尾至少十个小时……")` ——答案在纸上，不在她嘴里。
5. **长度上限 26 个汉字，停留 ≤4.5 秒。** 超过这个长度的句子说明它应该是一件物品或一个画面。唯一的例外是原片里她自己的原话（"来都来了""我开心了一下""相当于一屁股一屁股把自己抬升了一千六百米""特别特别幸运，我带了一盏拍视频用的补光灯"），且这些必须挂在对应的**动作**上，不能挂在"走进来"上。
6. **密度**：任何两句之间至少 6 秒；任何节点在玩家做出第一个动作之前，屏幕上的文字不超过一行独白 + 常驻的地点时间条。
7. **禁止**：任何提醒、劝阻、复盘、解释巧合、评价玩家选择的句子。系统从不说"你错了 / 做得好 / 可以试试"。任何一句读起来像"你应该"或"这说明"的文字都是 bug。

### 10.3 什么替代旁白

| 原来由文字承担的 | 现在由什么承担 |
|---|---|
| 现在几点了、还剩多少光 | 天上的太阳高度、阴影方向、Sassolungo 上那道橙粉、手机锁屏、地图边缘的日落刻度尺 |
| 我累不累 | 呼吸声、手抖、镜头下沉、她伸手时的犹豫 |
| 灯还能撑多久 | 光圈的直径与颜色（冷白 → 黄 → 跳动的暗红） |
| 该往哪走 | 石头上的红白漆、路牌上的字、地图上那条线、公路的方向（听得见） |
| 我知道些什么 | 本子（玩家自己翻开才看得见） |
| 这里发生了什么 | 声音先到并且偏在一侧，玩家因为听见了才转头 |
| 这一天我做了什么 | 相册（警察局那一幕的收据） |

### 10.4 保护的原文

以下文本不得改写、扩写或提前：信件原文与译文（`LETTER_LINES_IT` / `LETTER_LINES_ZH`）、那位女士的两句（`"Have you lost your phone?"` / "这个公交车去警察局"）、警察摊手、她结尾的三句总结（`CLOSING_LINES`，只在片尾出现一次）。**全游戏只有两处成段文字**：信件与结尾三句，它们都放在最后，一次给完，那时游戏已经不再需要玩家操作。

## 12 验收标准

审查代理据此逐条打回。**任何一条不达标即整体退回。**

### A 形式与可玩性

- **A1** 每个节点至少有 **2 个**需要玩家判断的可选动作（不含必做的那一个），且屏幕上没有任何东西告诉玩家它们存在。
- **A2** 一个什么都不碰只按"往前"的玩家能通关，**且他的这一天明显更暗、更快、更空**（相册更少、本子更少、天色更黑）。
- **A3** 至少 **6 个**节点存在真正的错误出口或错误选择（meadow / approach / crack / plateau / signpost / forest1），走错只花分钟，永远能回来。
- **A4** 至少 **3 个**死路节点（slab / ledge / hutTurn 或其降级过场）可以走进去、看一眼、走回来，**回头箭头始终存在**。
- **A5** 全游戏**没有一处**用 `setTimeout` 替玩家触发剧情节拍。攀登者、直升机、鹿、第一辆车、那位女士全部由 `onGaze` 触发。
- **A6** 第二天没有任何完成门槛；第三天公交站的 40 秒窗口只允许做完两件事。
- **A7** 没有 game over、没有死亡、没有重来点、没有分数或结算评价。

### B 忠实性（与 `SOURCE_TRANSCRIPT.md` 逐条对照）

- **B1** 事件顺序与事实文件完全一致；信箱在飞拉达半途（2,379 m）；手机在警局归还。
- **B2** **拍下那封信不是一个可以拒绝的选择。** 打开盒子并读到那一页即拍下；"把纸带走"必须以她自己收回手告终。
- **B3** 急转弯上**永远是第一辆过、第二辆停**，不存在任何可错过的时间窗口导致出现第三辆车。
- **B4** 那两位攀登者**不提供任何信息**（不说山屋耗时、不说时间）。
- **B5** 112 通话**永远徒劳**，无论玩家试几次、说什么。
- **B6** 第二天**任何顺序、任何彻底程度都找不到手机**，且**没有任何线索指示手机的去向**。
- **B7** 第三天警察**只有摊手**，不补充任何关于手机何时抵达、由谁送来的信息。
- **B8** 不存在"素材还要不要"的可玩分支；不存在"没拍信"的第二结局；不存在"没在长椅上译完"的结尾变体。
- **B9** 没有发明的可读数字：**不得出现印在牌子上的 472 末班时刻**（原片无此数字）。
- **B10** 所有推断出来的物件（旧锚栓、电话册、路牌石堆上的编号、信箱里的其他页）**只作布景，不驱动任何数值**。空水壶不得出现。

### C 叙事

- **C1** 全程无入场自动播报；`thoughts` 只在进入后 2 秒无动作时兜底，一局最多三次。
- **C2** 任意连续 60 秒的游玩录像里，屏幕上有文字的时间不超过 40%。
- **C3** 独白单句 ≤26 字（原片原话除外），任何两句之间 ≥6 秒，永不排队。
- **C4** 她不复述任何玩家能自己读到的东西。**特别检查**：`chooseRetreat()` 不得念出地图的答案。
- **C5** 没有一句提醒、劝阻、反思或解释巧合的话。她的总结只在片尾出现一次，用原话要点。
- **C6** 信件原文与译文、女士的两句、警察摊手、结尾三句一字未改。
