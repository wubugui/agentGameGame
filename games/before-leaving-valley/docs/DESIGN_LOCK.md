# 《离开山谷以前》设计锁定 v1.0

状态：**LOCKED**  
用途：后续原型、剧本、美术和程序迭代的共同约束。除非试玩证据证明方向错误，不再更换核心形式。

## 1. 一句话定义

一款约 35–50 分钟、桌面浏览器优先的**角色化第一人称 2.5D 旅行冒险游戏**：玩家暂时成为一位独自旅行的年轻女孩，在一次临时起意的山间探索中欣赏风景、克服困难、误入险境、靠自己走出黑暗，得到陌生人的帮助并结识朋友；在接受手机遗失后，它又毫无预兆地回到手中，直到最后才想起途中偶然拍下的那封信。

## 2. 作品真正讲什么

游戏主体讲“一位年轻女孩出去冒险的一天”，不是关于命运、灵异、登山执念或苦难。

“命运感”只在结尾出现：此前互不相关的偶然，在手机失而复得以后被重新理解。游戏不证明命运存在，只允许玩家短暂地产生这种感觉。

体验目标：

> 玩家花整场游戏完成一次属于自己的冒险，只在最后一分钟产生一次关于命运的念头。

## 3. 最终形式

### 3.1 类型

- 角色化第一人称叙事冒险
- 2.5D 插画式连续场景
- 轻量徒步、攀爬、观察、拍照、寻路、求助与搜索
- 单线、单结局

### 3.2 不是以下形式

- 不是第三人称角色动作游戏
- 不是《孤山独影》的简化复制品
- 不是静态热点点击或视觉小说
- 不是自由攀爬模拟器
- 不是开放世界、生存游戏或资源管理游戏
- 不是恐怖、悬疑解谜或超自然调查

### 3.3 空间呈现

每个地点是一幅由 GPT Image 制作并拆分的宽幅场景板：前景、中景、远景、局部动画与交互层彼此独立。玩家可以有限度环视，并沿作者设计的路线连续移动；移动通过镜头推进、视差、脚步、身体晃动、遮挡转场和手部动作完成，不允许再以瞬间切图代替行走。

世界不是完整 3D，但必须让玩家相信地点彼此相连、路是自己走过的。

## 4. 主角锁定

主角是一位约 23–26 岁的年轻女性，普通城市生活背景，有独自旅行经验，但不是专业登山者。

她的核心特质：

- 好奇、鲜活、容易被风景吸引
- 有一点临时起意和对风险的低估
- 会害怕，但遇事具有行动能力
- 不把自己当英雄，也不沉溺于苦难
- 获救后能很快恢复说笑，与陌生人建立真实关系

第一人称不意味着空白主角。玩家不是用现实身份覆盖她，而是暂时住进她的身体。

### 4.1 侧面塑造渠道

- 可见的手、袖口、鞋、发圈、手链和背包带
- 有个性的手机壳、挂件、锁屏和桌面
- 相册中的日常、朋友、宠物、通勤晚霞和旅行照片
- 与朋友及家人的少量聊天记录
- 拍照习惯、物品摆放和生活化自言自语
- 紧张时的呼吸、反复确认和细小身体动作

禁止用粉色、美甲、化妆品等符号清单替代人物塑造；每个物件都必须体现她如何生活或行动。

## 5. 设计支柱

### 支柱 A：这是一次完整的冒险

从交通抵达、开始徒步、被风景吸引、克服地形、到达高处、察觉危险、夜间下山、获救、搜索手机直到离开，必须形成连续的一天。至少 60% 的有效游玩时间用于探索、移动、观察与克服困难。

### 支柱 B：玩家亲手走过这段路

路线和困难不能只由旁白宣布。玩家要观察方向、选择前进点、完成简单身体交互，并能回头看到走过的距离。攀爬只服务于身体参与感，不追求模拟深度。

### 支柱 C：她是一位具体的年轻女孩

不展示持续可见的第三人称模型，但要通过身体、手机、声音、选择习惯和个人物件持续建立身份。换成一个中年男性后，所有角色细节和情绪都应明显不成立。

### 支柱 D：世界先通过普通人接住她

救援者不是功能性 NPC。获救、坐进车里、恢复体温、交谈、共同返回搜索，构成一段有生活温度的关系发展。陌生人成为朋友，是奇迹发生前更重要的现实善意。

### 支柱 E：命运只是一层事后余韵

信件不预言、不警告、不发光、不制造恐怖。手机归还没有灵异特效、因果解释或戏剧化揭晓。结局停留在“怎么会这么巧”的轻微失重感。

## 6. 核心循环

> 发现令她好奇的目标 → 决定靠近 → 观察路线 → 用轻量交互克服阻碍 → 得到风景或经历 → 决定是否继续

核心动作只有四类：

1. **移动与观察**：沿连续路线前进，环视环境，回望走过的路。
2. **轻量通过**：抓扶、跨越、平衡、选择落脚点；失败只导致短距离滑回与时间推进。
3. **手机使用**：地图、时间、电量、拍照、相册、电话与最后的内容回看。
4. **人与人互动**：求助、简短对话、共同搜索和建立信任。

不引入传统背包、物品合成、技能树、数值化饥渴、战斗或复杂谜题。

## 7. 三个关键交互

### 7.1 攀爬 / 通过

- 玩家观察画面中的 2–3 条可行路线。
- 选择下一个抓扶点或落脚点，角色自动完成具体肢体调度。
- 安全、勉强、危险通过呼吸、手部颤动、镜头和声音表达，不显示耐力条。
- 失败滑回最近的平台，不死亡、不读档。

### 7.2 拍照

- 相机保存玩家当时真实构图，而不是解锁预制收集图。
- 风景照片完全可选，但游戏必须自然诱导玩家主动拍摄。
- 信件只是旅途中一张容易被遗忘的照片。
- 手机归还后，相册成为玩家自己这次冒险的证据。

### 7.3 夜间下山

- 玩家一手持手机照明，在有限光束中寻找路线和落脚点。
- 电量是叙事压力，不做可计算的最优资源题。
- 恐惧来自视野受限、时间和孤独，不来自怪物或灵异线索。

## 8. 情绪与流程结构

| 段落 | 目标时长 | 主要感受 | 主要玩法 |
|---|---:|---|---|
| 抵达与开始探索 | 5 分钟 | 轻松、期待、人物亲近感 | 交通、手机、徒步 |
| 被风景吸引 | 8 分钟 | 自由、好奇 | 观察、岔路、拍照 |
| 克服地形并登高 | 10 分钟 | 身体参与、自豪 | 轻量攀爬、回望路线 |
| 高处与信件 | 3 分钟 | 满足、偶然的小发现 | 休息、拍照、看不懂后离开 |
| 迟来的危险意识 | 3 分钟 | 认知翻转 | 查看地图、时间、日落 |
| 夜间自救 | 8–10 分钟 | 恐惧、专注、坚持 | 手电、寻路、滑倒、继续前进 |
| 获救与新朋友 | 5 分钟 | 放松、温暖、恢复说笑 | 求助、对话、车内交流 |
| 返回寻找手机 | 6–8 分钟 | 希望被磨灭、关系加深 | 公路搜索、拨号、回忆路线 |
| 接受与归还 | 3–5 分钟 | 遗憾、释然、惊喜、余韵 | 放弃、意外归还、相册、想起信 |

## 9. 信件与手机的叙事规则

### 信件

- 首次出现不超过 45 秒。
- 当时不提供翻译，也不标记为关键物品。
- 不使用年份、外语预言、神秘音效等人为悬疑装置。
- 精确内容以原始经历为准，在剧本阶段确认，不擅自编造。
- 结尾只作为回声，不承担谜底功能。

### 手机

- 从开场起频繁、自然地使用，形成玩家习惯。
- 丢失时不弹“手机已丢失”，而是通过伸手摸空两个口袋完成发现。
- 搜索过程中可借朋友手机拨打，但始终无回应。
- 归还时由玩家第一人称亲手接过。
- 归还后的第一件事是看到自己拍摄的照片，而不是观看解释性过场。

## 10. 美术与声音

### 美术

- 现实主义基础上的轻绘画感，不走阴森恐怖风。
- 白天自然、明亮、令人想继续向前；夜晚可信且有限可见。
- 角色身体建立固定参考：外套袖口、手、鞋、饰品和手机必须跨场景一致。
- 第一阶段目标为 12–14 张主场景板，而不是重复使用 3 张背景调色。

建议场景：交通窗外、下车点、林间入口、开阔山路、铁索岩壁、高处平台、信箱地点、日落岔路、夜间坡道、密林出口、公路、车内、返回搜索路段、离开山谷。

### 声音

- 风、脚步、布料、铁索、呼吸、碎石、手机操作、车内暖风承担主要叙事。
- 安全探索和观景处可出现极少量音乐。
- 高压攀爬与夜间自救以环境声和呼吸为主。
- 手机归还不使用惊吓音效或神圣音乐；结尾音乐在认出照片以后才缓慢进入。

## 11. 技术锁定

- **运行平台**：桌面浏览器优先，GitHub Pages 发布。
- **技术栈**：TypeScript + React + PixiJS。
- **React**：手机界面、对话、设置、存档和可访问性。
- **PixiJS**：2.5D 场景、视差、镜头、路线移动、手部动画、光照和环境特效。
- **逻辑分层**：数据驱动的章节/场景状态机，不在组件中散落剧情判断。
- **存档**：章节检查点 + 相册内容，使用本地存储。
- **目标分辨率**：16:9，1280×720 逻辑画布，自适应桌面窗口。
- **输入**：鼠标 + 键盘；触屏适配不进入首发范围。

选择该栈的理由：继续保留网页试玩和快速获得反馈的优势，同时用专门渲染层替换当前 DOM 幻灯片式场景；不承担完整 3D 环境、角色模型、绑定和动作资产成本。

## 12. 范围锁定

首个完整版本只包含：

- 1 位第一人称主角
- 1 条主线路和 1 个结局
- 2 位有性格的救援者 / 新朋友
- 12–14 个主场景板
- 3 类主要直接交互：通过地形、拍照、夜间寻路
- 1 段可玩的共同搜索
- 35–50 分钟总时长

明确不做：

- 完整 3D、开放世界、自由攀爬
- 多结局、道德选择和分支剧情
- 背包、合成、生存数值、战斗
- 怪物、鬼影、命运实体或明确超自然解释
- 大量 NPC、支线任务、收集品系统
- 全程配音和电影式长过场

## 13. 最终验收问题

未经提示完成试玩后，玩家反馈需要满足：

1. 多数玩家首先用“旅行、冒险、爬山、迷路”描述游戏，而不是“命运、恐怖、解谜”。
2. 玩家能用性格词描述主角，并明确感到她是一位具体的年轻女孩。
3. 玩家认为危险来自正常冒险中逐渐形成的处境，而不是编剧突然施加的灾难。
4. 玩家既感到主角靠自己走出了困难，也感到陌生人的帮助真实可信。
5. 玩家在找不到手机时真诚遗憾，在归还时感到“太巧了”“被世界接住了”，而不是“闹鬼了”。
6. 结尾想起信件时，玩家产生回望整段旅程的冲动，而不是等待谜底解释。
